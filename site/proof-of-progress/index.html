Less friction, fewer assumptions

Capture and retrieval are bounded capabilities. A browser demonstration is not native Android interception, autonomous account access or an always-on recorder.

This public page contains no scripts, trackers, private data payload or direct private-document links. It does not read a browser workspace database. A URL path is not an authentication boundary; broader hosting and history protections require separate review.

Publication policy: positively select public material. Keep everything uncertain private. Removing a current link cannot recall previously downloaded or externally cached copies.
