Counterpatterns

The useful subversion is less attention extraction and less vendor lock-in through explicit intent, reversibility, portability and user-owned context — not bypassing access controls.

IntentShield

Capture and pin the reason for opening an app before any feed appears.

Quiet Start

Open to pinned intentions, drafts and active people/projects instead of engagement content.

Feed Gate

Keep algorithmic/autoplay material closed until the user explicitly chooses it.

Session Return

Restore the exact task, draft, search or person after distraction.

MissedClick Undo

Give accidental navigation a short reversible grace period.

PasteGuard

Preview long multiline text, boundaries and duplicate auto-thread segments before posting.

Context Capsule

Export a clean model-agnostic state packet instead of relying on one vendor's chat history.

Local Memory Vault

Keep user-owned context local with selective recall and explicit export.

Provenance Lens

Distinguish user-authored, AI-assisted, recovered, revised and derivative material.

Conversation-to-Artifact

Turn a chat into HTML/PDF/Markdown/JSON plus an evidence manifest.
