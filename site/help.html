The complete round trip

Use ChatGPT in three steps

No account connection is required. This version uses deliberate copying and pasting, not automatic synchronization.

1

Prepare one intention

In Continuity, open Use ChatGPT. Choose your intention. Keep the suggested question or type your own. Select Prepare text for ChatGPT.

Only this intention's fields are included by default. Leave evidence excerpts unchecked unless they are needed. Read the outgoing text before sharing it.

Example question: “What is one useful next action? Keep guesses separate from facts.”
2

Copy, switch, and ask

Select Copy text for ChatGPT. Switch to ChatGPT, paste the text into a conversation, and send it. Opening ChatGPT alone does not transfer or send anything.

Read the answer. Copy the whole answer when it includes exactly one JSON code block, or use that code block's Copy button. You do not need to understand or edit the code.

3

Return, compare, and approve

Return to Continuity in the same browser or installed app. Under Step 3: Review ChatGPT suggestions, paste the answer. Select Compare suggested changes.

Compare Current and Proposed. Check only the changes you agree with, then select Save approved changes. Nothing is preselected. Original source text and reviewed evidence stay unchanged.

What is the JSON for?

It is a small structured return slip that matches the suggestion to the correct request. It is not a command. The app rejects unknown requests, outdated records, unsupported fields, and multiple code blocks rather than guessing.

Example: accept one suggestion, reject another

Your saved Next says “Work on the article.” ChatGPT proposes “Draft one supporting example” and also changes your goal to “Write a book.” Check Next action only. Leave Desired outcome unchecked. Saving applies the useful step without changing your goal.

What belongs in each field?

The words below are examples, not evidence. Use your actual circumstances.

Name
A short label you will recognize: “Finish the article.”
Desired outcome
What success looks like: “Publish a clear article for new readers.”
Last recorded step
What actually happened or where you stopped: “Drafted the introduction.” Not just “Article.” A filled field is not independent verification.
Next action
One step you can take: “Write the first example.” Not the distant outcome “Become successful.”
Open questions
Unknowns to investigate: “Which reader should this target?” A concern is not a proven cause.
Progress state
Whether you can continue, are working, are waiting, are blocked, or have finished. See the state guide below.
Specific reply / blocker
A real pending response or prerequisite: “Awaiting the editor's reply to Monday's email.” Leave blank when no actual wait is known.
Difficult is not the same as blocked.

A barrier makes work harder. A dependency is a prerequisite. Waiting means an identified response or event is pending. Next is an action you control.

Waiting for one reply does not stop an entire project when other useful work remains. Keep that project on CONTINUE and record the specific pending response separately. Do not erase a known obstacle merely to tidy the form.

Explain all seven progress states
CONTINUE
A useful next action is available.
PROCESSING
You have marked the work as underway. This does not mean an AI is working in the background.
WAITING
Progress primarily depends on a specific external reply or event.
BLOCKED
An identifiable prerequisite prevents the required work.
RESOLVED
You consider the intention complete or settled.
REFERENCE
Information to keep, without an active task.
ARCHIVED
Retained as history, no longer active.

When something does not work

ChatGPT gave me words, but no JSON block

Reply in the same chat: “Please return one ContinuityFormReply/1 JSON code block using the original requestId and only the allowed fields.” Then copy that block back.

“No matching request on this browser”

Return to the browser or installed app where you prepared the request. Browser profiles keep separate records. Prepare a new request from the correct workspace if needed; do not invent or alter the request ID.

“The intention changed after this request”

A newer edit is protected. Prepare a fresh handoff and ask again. The app will not overwrite newer work with an outdated reply.

The answer has several code blocks

Copy only the block containing ContinuityFormReply/1, or ask ChatGPT for exactly one block. Do not paste several competing replies.

Copying or sharing failed

Use the outgoing text box to select and copy manually, or select Download text file. Native sharing is device-dependent. A completed share dialog does not mean ChatGPT received or answered the request.

The app looks empty after switching browsers

Return to the original browser. Your records may still be there. Back up or transfer the project before moving to another browser, profile, or device. Do not clear storage to troubleshoot.

Can ChatGPT read or update Continuity directly?

Not in this release. The copy/paste handoff is the working connection. A private, permission-controlled connector and in-app model calls remain separate future work. This app does not ask for an API key or upload your archive.

Get the update without losing work

Open the browser or installed app that already contains your records. Save current work and export a backup. Open Device & drafts, select Check for app update, then use App update ready · save & apply when it appears. Confirm the reload.

Look for v0.20.1. If an update is not yet offered, check again while online. Do not clear browser data. Updating the app shell does not require replacing your workspace.

This guide is cached for offline use after the updated app has installed its offline shell. ChatGPT still requires its own connection. Offline storage is not a backup and is not encrypted working storage.
