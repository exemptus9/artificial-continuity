# Project context entry point

The reusable context bridge is documented in [docs/PROJECT_CONTEXT.md](docs/PROJECT_CONTEXT.md).
Run [tools/context_store.py](tools/context_store.py) only against a separately stored private context file.

This public repository is the application/tooling source, not the user's private
operational registry. Read the user-designated private context location through
the available connector. Do not seed personal project/life context into this
repository, its issues, pull requests, Pages artifacts, or test logs.

Read current state → inspect authoritative evidence → propose a minimal update →
explicit approval → checked save → reload verification → scoped future handoff.

No automatic cross-chat capture, background sync, browser-data access or native
Android interception is enabled by this file. Preserve the existing product
family and source history; do not create duplicate products to obtain continuity.
